# 禁止右转 · 离线浏览器测试修订版 V1.4

## 运行
下载解压后直接双击 `index.html`，使用 Windows Chrome 或 Edge 打开。不需要本地服务器、插件或联网。也可单独复制 `index.html` 打开。

## 实际验证
Chromium 使用 `page.set_content` 将与离线入口一致的 HTML/JS 注入空白浏览器页面，成功完成四模块切换、作品筛选、详情弹窗、元素添加、透明度调整、缩放、描边开关、撤销重做和 PNG 下载，未出现 JavaScript 异常。由于执行环境禁止直接导航本地 `file://` URL，因此未能在此环境中完成双击文件这一系统级动作验证；代码中已检查无模块脚本、无 fetch 请求且仅有内嵌脚本及 CSS。

## 素材
开场 CG 路径 `assets/opening/opening.mp4` 可选。缺失时自动切换到 SVG 动态占位。艺术家画作仍使用明确标注的原创占位图，不可视为原作。

## 修改源码
直接双击运行的是 `index.html` 内嵌版本。`js/` 与 `data/` 内为维护源码备份，不会自动同步到 HTML，修改后需重新构建。
